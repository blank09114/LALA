# 🛒 LALA 장바구니 시스템 사용법

## ✅ 완료된 기능

### 1. 강의 상세페이지 (mainLectureDetail.html)
- ✅ "수강신청" 버튼을 "🛒 장바구니 담기" 버튼으로 변경
- ✅ 버튼 클릭 시 localStorage에 강의 정보 저장
- ✅ 이미 담긴 강의는 "✅ 장바구니에 담김" 상태로 표시
- ✅ 토스트 알림 메시지 표시

### 2. 장바구니 페이지 (cart.html)
- ✅ localStorage에서 강의 목록 불러오기
- ✅ 강의별 체크박스로 선택 관리
- ✅ 전체 선택/해제 기능
- ✅ 개별 강의 삭제 기능
- ✅ 실시간 결제 금액 계산 (할인 적용)
- ✅ 빈 장바구니 상태 안내

### 3. 전역 기능
- ✅ 장바구니 개수 배지 자동 업데이트
- ✅ 브라우저 새로고침 시에도 데이터 유지
- ✅ 중복 추가 방지
- ✅ 데이터 유효성 검사

## 🧪 테스트 방법

### 1. 강의 상세페이지 테스트
1. `/course/detail/{lectureId}` 페이지 접속
2. "🛒 장바구니 담기" 버튼 클릭
3. 성공 토스트 메시지 확인
4. 버튼이 "✅ 장바구니에 담김"으로 변경되는지 확인
5. 다시 클릭해도 중복 추가되지 않는지 확인

### 2. 장바구니 페이지 테스트
1. `/users/mypage/cart` 페이지 접속
2. 담은 강의들이 표시되는지 확인
3. 체크박스로 선택/해제 테스트
4. 전체 선택 기능 테스트
5. 개별 강의 삭제 테스트
6. 결제 금액이 실시간으로 업데이트되는지 확인

### 3. 브라우저 개발자 도구에서 테스트
```javascript
// 콘솔에서 장바구니 상태 확인
LalaCart.getCart()

// 장바구니 개수 확인
LalaCart.getCartCount()

// 총 금액 계산
LalaCart.calculateTotal()

// 장바구니 비우기
LalaCart.clearCart()
```

## 🔧 추가 개발 가능한 기능

### 1. 헤더에 장바구니 개수 표시
```html
<!-- 공통 헤더에 추가 -->
<a href="/users/mypage/cart">
    🛒 장바구니 
    <span id="cartCount" class="cart-badge">0</span>
</a>
```

### 2. 장바구니 드롭다운 미리보기
- 헤더의 장바구니 아이콘에 마우스 오버 시 미리보기
- 최근 담은 강의 2-3개 표시

### 3. 찜하기 기능과 연동
- 찜한 강의를 장바구니로 이동
- 장바구니에서 찜하기로 이동

### 4. 장바구니 공유
- 친구에게 장바구니 내용 공유
- URL로 장바구니 상태 저장

### 5. 자동 삭제 기능
- 일정 기간 후 자동으로 장바구니에서 제거
- 사용자에게 알림 제공

## 🐛 문제 해결

### Q1: 장바구니에 강의가 표시되지 않아요
**A1:** 브라우저 개발자 도구(F12) → Console 탭에서 오류 메시지 확인
```javascript
// 디버깅용 코드
console.log('장바구니 데이터:', localStorage.getItem('lala_lecture_cart'));
```

### Q2: 버튼을 눌러도 반응이 없어요
**A2:** JavaScript 파일이 제대로 로드되었는지 확인
- Network 탭에서 cartManager.js 파일 로드 상태 확인
- Console에서 `LalaCart` 객체 존재 여부 확인

### Q3: 페이지 새로고침 후 데이터가 사라져요
**A3:** localStorage는 도메인별로 저장되므로, 같은 도메인에서 접속했는지 확인
- `localhost:8080`과 `127.0.0.1:8080`은 다른 도메인으로 취급됨
